## Reading the status badges

- CI badges follow the latest workflow run on `main`, which may be older than the latest commit. They do not summarize pull requests or every workflow in a repository.
- AI Host and Terminal Host validate packages in their release workflows. Spec Validator currently runs its validation on version tags, so its badge follows the latest release run.
- Community currently has a specification publishing workflow, rather than a package build workflow. Its badge reports docs status only.
- npm entries show publication status and the registry’s `latest` version, which can differ from the version in source. Packages without a `latest` tag are labelled explicitly. “Not published” means the package is not available from the public registry; “—” means the repository has no public npm package.
- Repository entries are maintained in this README. npm status is checked hourly by [Refresh npm status](https://github.com/lapismd/.github/actions/workflows/refresh-npm-status.yml); GitHub may delay scheduled runs. The Organization badge reports this refresh workflow. Registry errors preserve the previous npm status. Build badges refresh automatically.
