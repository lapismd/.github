## Reading the status badges

- CI badges follow the latest workflow run on `main`, which may be older than the latest commit. They do not summarize pull requests or every workflow in a repository.
- AI Host and Terminal Host validate packages in their release workflows. Spec Validator currently runs its validation on version tags, so its badge follows the latest release run.
- Community currently has a specification publishing workflow, rather than a package build workflow. Its badge reports docs status only.
- npm badges show the current published version, which can differ from the version in source. “Not published” means no package from that repository is currently available on npm; “—” means the repository has no public npm package.
- Repository entries are maintained in this README. Build and package badges refresh automatically.
